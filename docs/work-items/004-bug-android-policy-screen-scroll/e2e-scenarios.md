# E2E scenarios

1. Open Profile → Policy (local copy path)
   - Tap Profile tab.
   - Tap Policy.
   - Confirm policy content is readable and screen remains responsive.
   - Tap Back and confirm return to profile list.

2. Open Profile → Policy (web policy URL path)
   - Launch with policy URL configured.
   - Tap Profile → Policy.
   - Confirm web policy view opens and accepts vertical scrolling gestures.
   - Tap Back and confirm return to profile list.

3. Long-content behavior
   - Use a small-height emulator/device.
   - Open policy page.
   - Confirm no stuck state while scrolling through content.
